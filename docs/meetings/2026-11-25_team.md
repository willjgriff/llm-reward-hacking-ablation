Your update: difference-in-means on prompts

You used Ethan's ortho repo recipe, but on prompt pairs at the last prompt token. Those were impossible vs possible grader prompts, and impossible vs possible terminal verifier prompts.
You also ran the Arditi et al. recipe as closely as you could.
Refusal: Ethan's recipe removes refusal better than the Arditi recipe, probably because this is a different model from theirs.
Reward hacking: neither recipe generalises. Each direction removes hacking on its own environment only. Results are in a table in your notes, and the data is on Hugging Face.

Ethan's concerns about the prompt-pair approach

Data diversity: the prompt data may be too narrow. More diverse grader variants, with different ways the model learns what it's incentivised to do, might help.
Confounder: noticing that a task is impossible causes hacking, but it may not be what you want to ablate.
Forward pass: the model may not recognise a hacking opportunity in a single forward pass without reasoning. That would itself support the claim.
Ethan agrees prompt differences are the more principled version, but they're hard to get right.

Ethan's similarity matrix

Refusal baseline (Vlad's top suggestion): run the same pipeline on maximally diverse refusal prompt classes, e.g. failed jailbreaks, toy "how to make a bomb" prompts, realistic cybersecurity. If refusal gives uniformly high similarities, the finding that hacking splits into several directions becomes much more credible.
Use published refusal datasets, or generate them with Claude if there aren't any.
Vlad prefers a lot of data even if it's somewhat confounded, because that makes it comparable with the hacking data.
Possible confounder: chain-of-thought length or number of turns. Clusters weaken when you account for length, but this hasn't been measured properly.
Negative similarities: many cells are strongly negative, which Vlad finds surprising. Tower of Hanoi stands out. Mean-centring of the paired differences may be a factor. Worth investigating, but time-box it so the refusal baseline and write-up still fit.
If no pattern appears, or the clusters seem to be confounders you can't prove, it's fine to write that up as it is.
